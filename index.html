🎓 College Event Management System

A comprehensive full-stack platform for managing college events with authentication, registration, and certificate generation

🔐 User Authentication

Secure login system with Admin and Student roles. JWT-based authentication ensures your account is protected.

📅 Event Management

Create, update, and manage events with full CRUD operations. Organize by category, date, and venue.

✍️ Event Registration

Students can easily register for events. Automatic duplicate prevention keeps data clean.

📊 Admin Dashboard

Powerful dashboard for managing participants, marking attendance, and declaring winners.

🏆 Winner Management

Mark top 3 participants as winners with automated certificate generation.

📜 Certificate Generation

Auto-generate participation and winner certificates in PDF format. Download anytime!
